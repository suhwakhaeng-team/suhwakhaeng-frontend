# 3차 UT

- 참가자: `/ut3`, 공통 `/ut` 또는 기존 UT 입구에서 비밀번호 `math`.
- 고정 순서: 사전 A형 4문항(기초 3 + 기출형 1) → 목표 문제 1개 학습 → 사후 B형 4문항 → 9개 항목 피드백. 참가자별 교차 배정 없음.
- 사전 결과는 기초 3개를 진단하되 목표 문제 통과로 인정하지 않는다. 학습은 목표부터 시작하며 오답/모름일 때 필요한 하위 노드로 내려가고, 부분 문제를 해결해도 목표는 자동 통과하지 않는다. 돌아온 목표는 숫자를 바꾼 문제다.
- 노드 9개: 개념(조건부확률, 덧셈정리, 여사건·드모르간) 3개, AN(관계식, 확률 복원, 분모, 분자, 최종 비율) 5개, 목표 BN 1개.
- 기출형 문항은 UT용으로 구성한 문제다. 사전 목표 정답 5/8, 사후 목표 정답 3/5, 학습 목표 정답 4/7와 7/10. 검사와 학습 문항의 원문·정답은 `ut3Model.ts`, 서버 JSON은 `ut3/question-bank-v1.json`에 일치시킨다.
- 기록은 별도 `ut3_participants` 테이블, `/api/v1/ut3`와 `suhwakhaeng:ut3:*` 키를 사용한다. UT1·UT2 참가 기록과 캐시를 재사용하지 않는다.
- 답안·정오·시간·학습 경로·설문은 서버에서 저장하며 검사 중에는 정답/개별 채점 결과를 숨긴다. 참가자 토큰, revision과 actionId로 인증·충돌·재전송을 처리한다.
- 피드백은 이름, 닉네임, 전체 난이도, 학습 경험, 좋았던 점, 아쉬웠던 점, 신분, 자유 입력 모의고사 등급, 선택 전화번호의 9개 항목. 마지막 검사 완료자만 한 번 제출하며 개인 정보는 세션 캐시 응답에 포함하지 않는다.
- 관리자: `/admin/ut3`의 참가자 상세에서 검사/학습/피드백 확인. `/admin/ut3.csv`와 `/admin/ut3-feedback.csv` 제공. 기존 관리자 인증 적용.
