# UT5 확률과 통계 진단과 학습

주소 `/ut5`, 입장 암호 `apple`. 공통 입구 `/ut`에서도 입장합니다. UT4의 주소·암호·기록은 유지합니다. 백엔드 UT5 변경과 함께 반영해야 합니다.

## 진행

닉네임 등록 → 사전 5문항 → 사전 결과 → 목표 문제와 필요한 개념 학습 → 사후 5문항 → 전후 결과·설문.

UT4 화면과 활동 형식을 재사용합니다. 목표 문제에서 시작하고 막힌 부분을 학습한 뒤 같은 목표로 돌아갑니다. 5개 목표는 공유 개념이 있는 경우에만 3개 지도로 묶었습니다. 개념 6개에 각 3개 참여형 활동이 있으며, 오답에는 짧은 힌트를 제공합니다. 학습 목표 문제도 선택지로 답합니다. 사후검사는 사전 문장·상황을 유지하고 숫자·보기·정답만 바꿉니다. 난이도의 통계적 동등성은 검증하지 않았습니다.

## 시간과 결과

시작 안내에서 테스트 시작을 누른 뒤 각 문항의 타이머가 시작됩니다. 제출 또는 모름을 누르면 그 문항의 시간이 고정됩니다. 안내를 읽는 시간은 포함하지 않습니다. 테스트 중 홈 이동과 개념 열기는 제한하고, 완료 후에는 점수 변경 없이 노드를 복습할 수 있습니다. 개념 재열람 제한 안내는 사후검사에만 표시합니다.

- `seconds`, `activeSeconds`: 탭이 보이는 동안 누적한 실제 풀이 초.
- `elapsedSeconds`: 처음 문항을 연 시점부터 제출까지 중단을 포함한 전체 경과 초.
- `startedAt`, `answeredAt`: 최초 열람과 서버 제출 시각(Unix 밀리초).
- `interruptions`: 탭 숨김·종료 후 재접속 등의 중단 횟수.
- `timingVersion=visible-active-v1`.

0.25초 간격으로 브라우저에 저장하고 재접속 시 복원합니다. 강제 종료 직전 최대 약 0.25초는 누락될 수 있습니다. 숨겨진 탭의 시간은 실제 풀이 초에 포함하지 않고 경과 초에 남습니다. 계산기 등 다른 창을 사용할 수 있습니다. 브라우저 저장소를 지우면 제출 전 시간은 복원할 수 없습니다. Web Locks로 같은 참가자의 중복 탭 측정을 방지합니다.

사전 완료 직후 정답 수·평균 시간·문제별 결과를 표시하고 홈에서 다시 볼 수 있습니다. 최종 결과에는 전후 문항별 시간과 정오답을 비교합니다. 모름의 원시 기록은 보존하지만 평균 시간의 합계와 분모에서 제외합니다. 모두 모름이면 평균은 ‘—’입니다. 오답으로 답한 시간은 포함합니다.

## 서버와 검증

API `/api/v1/ut5`, 관리자 `/admin/ut5`, CSV `/admin/ut5.csv`. 설정 `UT5_ENABLED=true`, `UT5_PASSWORD=apple`. 참가 기록과 문항 버전은 각각 `ut5_participants`, `ut5_question_banks`에 저장합니다. 최신 버전은 5이며 사후 응답을 이미 시작한 참가자는 기존 문항 버전을 유지합니다. 이전 버전은 과거 기록 재현용으로 보존합니다.

`npm run build`, `node --test tests/ut5*.test.mjs`로 검증합니다. 프론트 테스트용 문항 고정본은 `tests/fixtures/ut5`이며 백엔드 버전 1·4·5와 같습니다. 백엔드 `Ut5IntegrationTest`와 기존 `Ut4IntegrationTest`도 실행했습니다. 실제 Edge에서 사전 결과 진입·재열람, 문항별 시간, 사후 안내, 완료 후 복습을 확인했습니다.
