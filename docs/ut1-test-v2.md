# UT 검사 v2 · 문항 검토본

기초 5문항은 학습 시작점 확인, 응용 5문항은 목표 유형의 학습 전후 비교에 사용한다. 모두 숫자 입력이며 `모르겠습니다`도 가능하다. 기초 정답은 응용 오답과 별개로 인정한다.

A/B는 같은 조건 구조에서 숫자가 달라지는 병렬 폼이다. 수학 답안은 독립 열거로 검산한다. 실제 학생 대상 난이도와 폼 동등성을 검증했다는 의미는 아니다. A→B / B→A 순서를 교대하고 기존 v1 기록과 평균을 합치지 않는다.

## 1. 기초 확인 · product-1

A: 셔츠 4벌과 바지 3벌 중에서 각각 하나씩 고르는 방법의 수는?

정답: **12**

B: 셔츠 3벌과 바지 5벌 중에서 각각 하나씩 고르는 방법의 수는?

정답: **15**

풀이(A): 두 단계의 선택지 수를 곱합니다.

## 2. 기초 확인 · factorial-1

A: 서로 다른 카드 5장을 모두 사용해 한 줄로 놓는 방법의 수는?

정답: **120**

B: 서로 다른 카드 6장을 모두 사용해 한 줄로 놓는 방법의 수는?

정답: **720**

풀이(A): 각 자리에 놓을 수 있는 카드 수를 곱하면 $5!=120$입니다.

## 3. 기초 확인 · permutation-1

A: 학생 5명 중에서 회장, 부회장, 총무를 한 명씩 뽑는다. 한 사람이 두 역할을 맡을 수 없을 때 방법의 수는?

정답: **60**

B: 학생 6명 중에서 회장, 부회장, 총무를 한 명씩 뽑는다. 한 사람이 두 역할을 맡을 수 없을 때 방법의 수는?

정답: **120**

풀이(A): 역할이 다르므로 뽑는 순서를 구별하고 이미 뽑은 학생은 제외합니다.

## 4. 기초 확인 · combination-1

A: 학생 7명 중에서 역할 구별 없이 대표 3명을 뽑는 방법의 수는?

정답: **35**

B: 학생 8명 중에서 역할 구별 없이 대표 3명을 뽑는 방법의 수는?

정답: **56**

풀이(A): 뽑는 순서를 구별하지 않으므로 $_7C_3=35$입니다.

## 5. 기초 확인 · repetition-1

A: 4종류의 과자가 충분히 있다. 같은 종류를 여러 개 골라도 되고 같은 종류의 과자는 구별하지 않는다. 과자 4개를 고르는 방법의 수는?

정답: **35**

B: 4종류의 과자가 충분히 있다. 같은 종류를 여러 개 골라도 되고 같은 종류의 과자는 구별하지 않는다. 과자 5개를 고르는 방법의 수는?

정답: **56**

풀이(A): 종류별 개수를 정합니다. 별 4개와 칸막이 3개에서 $_7C_3=35$입니다.

## 6. 목표 응용 · application-1

A: 정수 $x,y,z$가 $x+y+z=10$, $x,y,z\ge0$을 만족한다. 순서쌍 $(x,y,z)$의 개수는?

정답: **66**

B: 정수 $x,y,z$가 $x+y+z=11$, $x,y,z\ge0$을 만족한다. 순서쌍 $(x,y,z)$의 개수는?

정답: **78**

풀이(A): 먼저 필요한 최솟값 0을 확보합니다. 남은 10개와 칸막이 2개를 놓으므로 $_12C_2=66$입니다.
