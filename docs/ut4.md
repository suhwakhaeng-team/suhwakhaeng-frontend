# 4차 UT

첨부된 「유저테스트 4차」 변경안과 본문의 중 난이도 두 문제를 추가한다는 확인을 반영했습니다.

## 참가 흐름

- 입구 `/ut`, 전용 화면 `/ut4`. 입장 암호는 **banana**이며 서버가 검증합니다.
  기존 `/ut1`, `/ut2` 입구에서도 이 암호를 입력하면 UT4로 이동합니다.
- 닉네임 등록 → 사전 A형 6문항 → 조건부확률 목표 문제 1개와 필요한 하위 학습
  → 사후 B형 6문항 → 기존 9개 항목의 피드백 설문.
- 기존 기초 3개와 기출형 1개는 UT3의 A/B 문제를 보존합니다.
  추가 2개는 첨부 본문에 번호가 붙은 두 문제이며 정답은 각각 **1/4**, **7/10**입니다.
  두 추가 문제는 제공된 그대로 사전·사후에 동일하게 사용합니다.
  하단의 ‘필요시 추가’ 하 난이도 문제는 포함하지 않습니다.
- 전체 6문항, 기초 3문항, 기출형 1문항, 추가 2문항의 결과를 구분합니다.
  검사 중에는 서버가 정답과 개별 채점 결과를 응답에 포함하지 않습니다.

## 반복 개념 설명

기본 개념 학습은 기존 참여형 활동으로 시작합니다. ‘개념 다시 확인하기’를 누른 횟수를
참가자·개념별로 서버에 저장하고 다음과 같이 설명을 바꿉니다.

| 개념 | 1번째 | 2번째 | 3번째 | 4번째 이상 |
|---|---|---|---|---|
| 조건부확률 | 기존 참여형 활동 | 전체 12명 기본 그림 | 조건 B만 남긴 그림과 전체 그림 | P(A\|B) 기호 읽기부터 세 그림으로 설명 |
| 확률의 덧셈정리 | 기존 참여형 활동 | 기존 참여형 활동 | A·B·교집합 → 겹침 빼기·합집합의 2단계 | 같은 2단계 |
| 여사건·드모르간 | 기존 참여형 활동 | 기존 참여형 활동 | A의 여사건 → 두 원 바깥과 합집합의 2단계 | 같은 2단계 |

- 첨부된 11개 그림을 `src/routes/dev/ut4/assets/`에 포함했습니다.
- ‘내가 만든 식’의 TeX 명령 중복 이스케이프와 명령 뒤 문자 결합을 수정했습니다.
  빈칸·덧셈·뺄셈·곱셈 상태를 모두 검사하며 3/3 제목은 ‘덧셈정리를 완성해 보세요’입니다.
- 개념 설명을 열거나 반복해도 풀던 답안과 문제 진행 상태가 유지됩니다.
  설명을 보는 것만으로 문제 정답 또는 목표 완료로 인정하지 않습니다.
- 새로고침·재접속 후에도 개념 확인 횟수를 복원합니다.
  재전송한 같은 actionId는 횟수를 중복 증가시키지 않습니다.

## 저장 및 관리자

- API `/api/v1/ut4`, 테이블 `ut4_participants`, 브라우저 키 `suhwakhaeng:ut4:*`.
  UT1~UT3의 답안·참가자·진도·캐시와 분리합니다.
- 서버 설정 `UT4_ENABLED`(기본 true), `UT4_PASSWORD`(기본 banana).
- 관리자 `/admin/ut4`, 참가자 상세 `/admin/ut4/{id}`.
  검사 6문항, 학습 과정, 개념 확인 횟수와 설문을 확인할 수 있습니다.
- CSV `/admin/ut4.csv`, `/admin/ut4-feedback.csv`. 기존 관리자 인증을 사용합니다.
  설문 개인 정보는 참가자 브라우저 캐시 응답에 포함하지 않습니다.

## 검증

```sh
node --test tests/ut4.test.mjs tests/ut4ConceptSupport.test.mjs tests/ut4WebUi.test.mjs
npx tsc -p tsconfig.ut4.json
```

백엔드는 `Ut4IntegrationTest`가 입장 암호, 6+1+6 진행, 서버 채점, 단계 제한,
재전송·충돌, 반복 개념 확인 저장, 참가자 분리, 설문 및 관리자 화면을 검사합니다.
`Ut4BrowserFixture`는 테스트 클래스패스에만 있는 로컬 H2 서버이며 운영 DB·AI를 사용하지 않습니다.

실제 Chromium에서도 데스크톱·모바일을 검증했습니다. 브라우저 검수 스크립트와
화면 캡처는 작업 공간 `experiments/verify-ut4.cjs`, `experiments/ut4-verification/`에 있습니다.
로컬 구현과 검증이며 운영 배포는 별도입니다.
