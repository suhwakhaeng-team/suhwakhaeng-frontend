# 학습 Knowledge Graph 로컬 체험

브랜치: `feature/knowledge-graph-preview` (기준 `origin/main`의 `bb1f002`). 운영 배포·PR·DB 변경 없음. 화면은 기존 수확행의 상단 내비게이션, 밝은 회색 배경, 흰 카드, 파란 포인트에 맞췄습니다.

## 실행

Node 24 이상과 기존 프로젝트 의존성을 사용합니다. 신규 패키지 의존성은 없습니다.

```sh
npm ci
npm run dev:graph
```

이미 node_modules가 있으면 첫 줄을 생략합니다. `http://localhost:18085/dev/knowledge-graph`를 엽니다.
`.env.graph`는 로컬 실행용 비밀 없는 설정이며, 미리보기는 로그인·API 연결이 필요하지 않습니다.
서버는 localhost에만 바인딩됩니다. 이 개발용 경로는 프로덕션 빌드에서는 등록되지 않습니다.

로그인된 앱에서는 홈의 **새 그래프 체험**, 기존 개념지도의 **새 그래프 체험** 버튼 → `/main/knowledge-graph`로 접근합니다.
기존 `/main/topology` 기능은 그대로 유지합니다.

## 체험 순서

1. 기본 화면은 Unit만 보여줍니다. 단원을 누르면 해당 Concept들이 펼쳐지고, 다시 누르면 접힙니다.
2. 확률분포 → 이항분포를 눌러 상세 정보, 직접/간접 선수개념, 학습 시작점 추천을 봅니다.
3. 앎·모름·미정을 변경하면 노드, 미니 지도, 단원 진행률, 전체 진행률이 동시에 갱신됩니다.
4. 상단에서 자료구조와 알고리즘을 선택하고 다익스트라를 검색합니다.
5. 다익스트라 → 우선순위 큐 → 힙을 따라 탐색합니다. 예제 상태에서는 힙부터 복습하도록 제안됩니다.
6. 선수 미니 지도의 뒤로가기로 이전 개념으로 돌아갑니다.
7. 상태 필터는 일치하지 않는 노드를 흐리게 합니다. **빈틈 경로**는 모름과 모든 선수 경로를 강조합니다.
8. 드래그/휠, 터치 이동/두 손가락 확대, 확대·축소·전체 보기 버튼을 지원합니다. 그래프 배경에 키보드 초점을 두면 방향키/+/−/0으로도 조작할 수 있습니다.
9. 새로고침 후에도 저장한 상태가 남습니다. 과목을 바꿔도 각 예제의 상태는 분리됩니다.

## 저장과 운영 경계

- 현재 자기평가는 `localStorage`에만 저장됩니다. 운영 문제·답안·진단 점수를 변경하지 않습니다.
- 키는 버전 / 사용자 UID / 데이터셋 ID로 분리됩니다. 로그아웃만으로 자기평가를 삭제하지 않으므로 같은 브라우저에서 같은 계정으로 다시 로그인하면 유지됩니다.
- 개발 전용 미리보기는 `local-preview` 별도 공간을 사용합니다. 예제의 초기 색상은 데모 데이터이며 실제 사용자 평가가 아닙니다.
- 같은 브라우저의 다른 탭에는 storage 이벤트로 동기화됩니다. 기기 간 동기화는 없습니다. 브라우저 데이터 삭제·시크릿 창 종료 시 사라질 수 있습니다.
- 저장소 접근 거부, 손상된 데이터, 용량 초과는 경고로 표시하며 실패한 변경을 저장했다고 표시하지 않습니다.
- 로그인된 `/main/knowledge-graph`는 기존 GET topology API를 자동 호출합니다. 실제 서버 조회는 이번 오프라인 체험 검증 대상이 아닙니다.
- 기존 API는 간선에 이름을 사용하므로 유일하게 해석할 수 없는 관계는 제외하고 경고합니다. 서버 진단 점수를 자기평가로 임의 해석하지 않아 서버 데이터의 자기평가는 기본 미정입니다.
- 운영 연동 시에는 별도의 자기평가 API/테이블과 Subject·Unit·Concept ID 기반 콘텐츠 관계가 필요합니다. 기존 `user_tag_mastery` 점수를 덮어쓰지 않습니다.

## 계산 규칙과 규모

- 선수 그래프는 전체 선수관계를 탐색하지만, 렌더링은 선택한 개념 포함 가까운 16개로 제한합니다. 더 많은 관계가 있으면 개수 안내를 표시하며 노드 클릭으로 이어서 탐색할 수 있습니다.
- 메인 그래프는 모든 단원 + 현재 펼친 단원의 최대 18개 개념만 렌더링합니다. 더 큰 단원은 이전/다음 개념으로 탐색하며 검색은 해당 페이지를 자동으로 엽니다.
- `getMissingPrerequisites`는 직접·간접 관계 전체에서 미정/모름을 반환합니다.
- `getRootLearningGaps`는 알려진 개념에서 멈추면서 미해결 경로의 가장 이전 시작점을 찾고, 선택한 개념부터의 경로를 제공합니다.
- 순환에 막힌 개념은 안전하게 순서를 정할 수 없다고 경고합니다. 지식 그래프의 누락·오류를 실제 학습 능력으로 단정하지 않습니다.
- 탐색은 반복문·visited set 기반입니다. 5,000개 개념 체인에 대해 검증했습니다. 수천 노드를 동시에 그리는 GPU/Canvas 렌더러는 아닙니다.
- 단원만 수천 개인 경우의 시각적 군집화, 화면 밖 단원 가상화, 편집/관계 생성 UI, 서버 동기화는 후속 범위입니다.

## 검증

```sh
npm run test:graph
npm run build
```

도메인/저장소 테스트 13개, TypeScript·프로덕션 빌드, 신규 코드의 ESLint 검사를 수행했습니다.
브라우저에서 단원 펼치기·검색·상태 변경·새로고침 유지·과목 전환·재귀 탐색·뒤로가기를 확인했습니다.
전체 `npm run lint`는 기존 AuthContext, OnboardingContext, AIConceptPage, HomePage, ReviewListPage, BnLevelTest, LevelTestPage의 8개 오류로 실패합니다. 이번 작업에서 그 파일들은 변경하지 않았습니다.
기존 공통 번들의 500KB 경고도 남아 있습니다. 새 그래프는 별도 lazy chunk입니다.
