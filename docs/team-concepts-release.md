# 팀 제공 개념 자료 운영 반영

## 사용자 화면

- `/concepts`: 로그인 없이 자료를 읽는 전체 설명서. 95개 항목, 23개 그림을 보존하며 태그·단원·본문 검색과 번호가 있는 기출의 단계별 풀이 공개를 제공한다.
- 일반 웹 상단의 ‘개념 설명’, 태그 목록의 ‘개념 설명 →’, 지도 노드의 ‘노트 보기’에서 접근할 수 있다.
- 기존 개념 노트 6개는 본문과 활동을 유지하고 보충 자료를 추가한다. 원자료가 있는 태그 54개에 설명을 제공하며 없는 7개는 새 설명을 만들지 않는다.
- UT1·UT2 개념 학습에 보충 설명을 제공한다. 기존 검사 문항, 숫자 변형, 서버 채점, 학습 통과 조건, 참가자 기록은 변경하지 않는다.
- 설명서의 기출 예제는 UT 채점이나 학습 통과 기록에 포함하지 않는다.

## 백엔드 참고 자료

95개 Markdown과 출처 catalog를 패키징한다. `team-concepts.enabled=true`이면 RAG 검색에 읽기 전용 참고 자료를 우선 제공하고, 매칭되지 않으면 기존 벡터 검색을 사용한다. 운영 기본 활성화, `TEAM_CONCEPTS_ENABLED=false`로 비활성화 가능하다. DB 내용, 임베딩 색인, 저장된 AI 노트를 자동 변경하지 않는다.

자료 자체의 전체 수학적 검토는 완료하지 않았다. 원자료의 잘린 조건부확률 표 4개는 명시적인 상황에 맞게 복구했고 catalog에 수정 전후를 기록했다. 이미지 자료를 AI가 시각적으로 해석하는 기능은 포함하지 않는다.

## 배포 제외

로컬 태그 지도 스냅샷, 추가 선수 관계, 레이아웃 실험과 관련 미완료 변경은 작업 폴더에 보존하고 운영 릴리스에 넣지 않는다. 원본 HTML과 그림은 수정하지 않는다. 운영 DB 마이그레이션·데이터 편집은 없다.
