# 도수분포표 로컬 학습 코스

실행: `npm run dev:graph -- --port 18087`

주소: http://localhost:18087/dev/frequency-learning

기본 주소는 다음 3단계를 순서대로 진행한다.

1. 기초 익히기(기존 단계형)
2. 상황에 적용하기(기존 이야기형)
3. 로그인한 계정으로 `FREQUENCY_TABLE_UT1` 실전 문제 3개 제출

앞 단계를 완료하기 전에는 다음 단계가 잠긴다. 평가는 최초 답안 기준 2/3 이상이면 통과하며, 문제·채점·시도 기록은 백엔드에서 관리한다. 평가 진입에는 UT 로그인이 필요하다.

실전 문제를 통과하면 UT 화면에서 도수분포표 노드를 통과 상태로 표시하고, 오늘의 추천 선두를 최빈값과 산점도로 전환한다. 기존 서버 추천은 그 뒤에 유지한다.

개발 중 개별 화면 확인용 주소:

- 버전 1 (단계형): `/dev/frequency-learning?version=1` — 기존 코스 유지.
- 버전 2 (이야기형): `/dev/frequency-learning?version=2` — 통학 안내 자료를 만드는 5개 장면. 예상 → 자료 분류 → 용어 확인 → 안내 완성 → 다른 반 자료로 독립 도전.
- 이야기형 완료 여부는 별도 `dev_frequency_story_v2_completed` 키로 저장함.
- Case 3 (신뢰구간): `/dev/frequency-learning?version=3` — 선수 용어 확인 → 표본 추출 → 재추출 → 표본평균 분포 → 표본 수 비교 → 임의 폭의 추정 구간 → 반복 신뢰구간 → 공식 계산 → 독립 적용.
- Case 3는 가상의 정규모집단(μ=40, 알려진 σ=6), 독립 임의추출, 모평균의 양측 z 신뢰구간만 다룸. 실제 통학 자료/모표준편차 미지의 t 구간/모비율은 포함하지 않음. `https://www.itl.nist.gov/div898/handbook/prc/section1/prc14.htm`의 조건과 정의에 따름.
- Case 3의 선수 확인 세 문항은 입문 확인용이며 전체 선수 진단이 아님. DB 숙련도와 연결하지 않고 모든 진행은 메모리에서만 유지. 표본평균 분포와 반복 구간은 실제 정규 난수 기반 결과이며 포함률을 신뢰수준에 맞춰 강제하지 않음.
- 버전 2의 장면/작성 중 답은 메모리에만 유지하므로 버전 전환/새로고침하면 처음 장면으로 돌아감. 완료 기록과 버전 1 진행은 유지.
- 버전 2 마지막 장면의 새 자료 카드는 마우스/터치로 끌어 순서를 변경 가능. 키보드 좌우 화살표도 지원. 자동 정렬/자동 도수 계산은 없으며 같은 숫자의 관측값도 별도 카드로 보존.

- 현재 개발 모드에서만 접근 가능한 별도 화면. 기초·이야기 학습 진행은 브라우저에 저장하고, 실전 평가는 로그인 및 백엔드 API를 사용한다.
- 기존 사이트의 파랑/회색/흰색 팔레트 사용.
- 두 버전의 단계 제목은 ‘○○해보기’로 할 일을 표시. 안내는 짧은 경어체를 사용하고 반복 부제·격려 문구는 최소화. 개념 정의와 조작 안내는 유지.
- 읽기 → 구간 카드 선택 → 도수 세기 → 예시와 표 완성 → 혼자 표 작성 → 작성 및 해석 도전.
- 단계별 `개념과 예시 → 혼자 풀기` 구분. 예시 활동 완료 후 미션 진입.
- 통학 시간/시험 점수/운동 시간 사용처 비교, 경계값 슬라이더, 자료 눌러 세기, 클릭 또는 끌어서 구간 분류, 잘못된 도수 수정, 설문 대상 인원 구하기.
- 실시간 도수와 피드백은 학습용 예시에만 제공. 독립 미션/복습에서는 자동 정답 표시 없음.
- 학습 완료와 복습 확인은 구분하며, 완료 상태를 실서비스 숙련도나 개념지도 상태로 전송하지 않음.
- 복습은 체험을 위해 바로 제공. 시간차 복습, 실제 학습 효과 검증, 여러 변형 문항은 미구현.
- 진행은 `dev_frequency_course_v1` 로컬 저장소 키로 격리. 체험 초기화는 이 코스 기록만 초기화.
- 학습 내용/통과 기준은 교수님 자문 및 학생 테스트를 위한 초안.
